# Navimetry branding asset slot

The integration skeleton intentionally does not invent a replacement logo.

Place the approved Navimetry master logo/icon sources here before the dedicated branding commit. That commit should replace user-visible KoggerApp logo/icon resources while preserving upstream copyright/license notices in About/Legal and source files.

Suggested source set:
- vector master (`.svg` preferred);
- Windows `.ico`;
- Android adaptive icon assets when mobile integration starts;
- README/header raster only if needed.
